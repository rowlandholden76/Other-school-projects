Android scaffold (Kotlin + Jetpack Compose)

How to open

- Open this folder in Android Studio: `android/`.
- Install recommended SDKs when prompted (API 33+ recommended).
- Build and run the `app` module on an emulator or device.

Notes

- This is a minimal scaffold generated to help start porting the desktop app.
- Implement cryptography and storage in a separate Kotlin module for reuse and testing.
- Prefer Android Keystore / EncryptedFile or Google Tink for secure storage.
